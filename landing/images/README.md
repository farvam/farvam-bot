# تصاویر پنل‌ها

هر تصویر را با همین نام (فرمت webp) در این پوشه بگذارید. تا وقتی فایلی نباشد، صفحه جای خالی نشان می‌دهد.

| فایل | کجای صفحه | اسکرین‌شات |
|---|---|---|
| acc-dashboard.webp | بالای صفحه (hero) | داشبورد حسابداری با کارت‌های تومان، طلا، نقره، دلار، یورو |
| acc-kpis.webp | ستون حسابداری | کارت‌های ترازنامه، جریان نقدی، تراز آزمایشی، سود و زیان |
| acc-cash-trend.webp | گالری حسابداری، صنف آبشده | نمودار روند موجودی صندوق |
| acc-inventory.webp | گالری حسابداری، صنف ویترین‌دار | موجودی و آبشده با برایند ۷۵۰ |
| acc-search.webp | گالری حسابداری، صنف سکه | جست‌وجوی پیشرفته اسناد |
| ops-home.webp | گالری عملیاتی | صفحه اصلی پنل عملیاتی (کاشی‌ها) |
| ops-cashflow.webp | ستون عملیات، گالری عملیاتی، صنف کیفی | گردش صندوق |
| ops-workshop.webp | گالری عملیاتی، صنف کارگاه | کارت کارگاه |
| ops-myaccount.webp | گالری عملیاتی | حساب من |
| mgmt-access.webp | ستون پرسنل، گالری مدیریتی | سطح دسترسی همکار |
| mgmt-branches.webp | گالری مدیریتی | شعبه‌ها و نیروها |
| mgmt-alerts.webp | گالری مدیریتی | اخطار و اعلان |
| mgmt-forms.webp | گالری مدیریتی | فرم درخواست همکاری و توافق‌نامه |
| trade-room.webp | ستون اتاق معاملات، صنف بنکدار | میز معاملات (هنوز ارسال نشده) |
