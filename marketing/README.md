# تبلیغات فَروَم

- `../site/` — سایت کامل با پنل مدیریت، مقاله‌ها و موتور توضیحات (راهنمای نصب: `site/README.md`)
- `ad-kit.md` — کیت کامل تبلیغات: راه‌اندازی کانال‌ها، کپشن‌ها، سناریوها، پیامک، اسکریپت تماس، تقویم ۳۰ روزه
- `social/` — تصاویر آماده پست (۱۰۸۰×۱۳۵۰)، استوری (۱۰۸۰×۱۹۲۰) و لوگوی پروفایل
- `templates/` — منبع تصاویر؛ بعد از ویرایش `social.html` اجرا کنید:
  `NODE_PATH=$(npm root -g) node marketing/templates/render.js`
