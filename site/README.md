# سایت فَروَم (نسخه PHP با پنل مدیریت)

## نصب روی هاست (cPanel / DirectAdmin)
1. کل پوشه `site` را با نام `farvam` در `public_html` آپلود کنید؛ آدرس سایت می‌شود `https://farvamcertification.ir/farvam/`.
2. دسترسی پوشه‌های `farvam/data`، `farvam/images`، `farvam/files` و `farvam/assets/fonts` را روی **755** (یا اگر ذخیره نشد **775**) بگذارید تا پنل بتواند تغییرات و فایل‌ها را ذخیره کند.
3. فایل `robots.txt` را به ریشه دامنه (`public_html/robots.txt`) هم کپی کنید؛ گوگل فقط robots ریشه دامنه را می‌خواند.
4. پنل مدیریت: `https://farvamcertification.ir/farvam/admin/`. رمز اولیه جداگانه به شما داده شده؛ بعد از اولین ورود از بخش «امنیت» عوضش کنید.
5. نقشه سایت `https://farvamcertification.ir/farvam/sitemap.xml` را در Google Search Console ثبت کنید.

اگر سایت را در ریشه دامنه می‌گذارید، در `config.php` مقدار `BASE_PATH` را `'/'` و `SITE_URL` را `https://farvamcertification.ir` کنید. اگر مقاله‌ها باز نشدند (هاست Nginx)، `PRETTY_URLS` را `false` کنید.

نیازمندی: PHP 7.4 یا بالاتر (پیشنهاد: 8.1+). برای تبدیل خودکار عکس‌ها به WEBP، افزونه GD با پشتیبانی WEBP لازم است.

## پنل مدیریت
| بخش | کاربرد |
|---|---|
| درخواست‌ها | همه فرم‌های «ماه رایگان» که از سایت ثبت شده، با خروجی اکسل |
| متن‌ها و لینک‌ها | همه متن‌های صفحه، شماره تماس، واتساپ، لینک پنل، آیدی کانال‌ها، پیشنهاد ماه رایگان، سئو، کد آمار |
| مقاله‌ها | افزودن، ویرایش، حذف و پیش‌نویس مقاله؛ خودکار در نقشه سایت |
| تصاویر | جایگزینی اسکرین‌شات‌های پنل |
| ویدیو و فایل | بارگذاری ویدیو، عکس بنیان‌گذار یا نسخه جدید پاورپوینت |
| ارائه معرفی | متن اسلایدهای معرفی تعاملی (`present.php`) |
| فونت تیترها | بارگذاری فونت شکسته نستعلیق یا نستعلیق کشیده دلخواه برای همه تیترها |
| موتور توضیحات | جمله‌ها و لحن‌های موتور معرفی پویا |
| ویرایش پیشرفته | ویرایش مستقیم JSON برای افزودن بخش یا صنف |

## صفحه‌ها
- `/farvam/` صفحه اصلی · `/farvam/for/vitrin` (و bonak، kifi، kargah، abshode، sekke) صفحه هر صنف
- `/farvam/present.php` معرفی تعاملی · `/farvam/files/farvam-presentation.pptx` پاورپوینت معرفی
- `/farvam/blog/` مقاله‌ها · `/farvam/sitemap.xml` نقشه سایت

بخش‌هایی که به اطلاعات شما نیاز دارند (نظر مشتری‌ها، قیمت‌ها، درباره ما، مهلت پیشنهاد، ویدیوها، اینماد، آیدی اینستاگرام) تا وقتی در پنل پر و روشن نشوند، در سایت نمایش داده نمی‌شوند.

## ساختار
- `index.php` صفحه اصلی · `blog/` مقاله‌ها · `admin/` پنل · `lead.php` ذخیره درخواست‌ها
- `data/content.json` متن‌ها · `data/articles.json` مقاله‌ها · `data/engine.json` موتور توضیحات · `data/leads.json` درخواست‌ها (خودکار ساخته می‌شود)
- `build-static.php` ساخت نسخه HTML ثابت برای هاست بدون PHP (بدون پنل و ذخیره درخواست)
